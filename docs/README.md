# Javelina Works Site — Documentation

Internal documentation for the Javelina Works landing site.

This site is built with [Astro](https://astro.build) and deployed to GitHub Pages.

## Contents

- [Deployment](./deployment.md) — How the site is built and deployed via GitHub Actions
- [Development](./development.md) — Local development setup, scripts, and conventions
- [Content](./content.md) — How site content is authored and configured

## Quick reference

| Task | Command |
| ---- | ------- |
| Install dependencies | `npm install` |
| Run dev server | `npm run dev` |
| Build production site | `npm run build` |
| Preview a build | `npm run preview` |
| Format source | `npm run format` |
| Type-check | `npm run astro-check` |

Node `>=22.12.0` is required (see `package.json` → `engines`).
