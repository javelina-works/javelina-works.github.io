# Rivet

A brass rivet whose glints slide around it toward each nearby light: the lamp (or the sun by day), a tube, and a green pilot or status light.

- Use brass in one or two places a page: the clamps of a LightTube and the plate under it, or one card that stands for something physical. Not every card.
- `Surface` with `rivets` puts one in each corner; a `Rivet` on its own can go anywhere inside a positioned element (`jw-rivet--tl`, `--tr`, `--bl`, `--br` place it in a corner).

## Props (React)
`className`, `style`.
